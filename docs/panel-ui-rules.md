# 边记部（Sideby Note）面板 UI 规则

面向后续改动的约束清单。历史复查的过程、逐项对照与截图已移除，只保留规则与待决项；
界面截图及重拍流程见 [截图 SOP](./screenshot-sop.md)。

基准：DSH 宿主的 UI / UX 设计规范（令牌、字号、描边、浮层、滚动条与无障碍条款）。

## 1. 令牌与尺度

| 规则 | 落地 |
| --- | --- |
| 只用 DSH 语义别名，不自建色板 | `--dsw-alias-*`（墨色 / 悬停 / 描边 / 状态 / 设置卡）；测试禁止 `#hex`、`rgb()` 与平行灰阶 |
| 字号只取三档 | 标题 14/500、行与按钮 13/400、说明与计数 12/400；行高统一 20，计数行 16 |
| 字重上限 500 | 层级靠字号与墨色，不用 600 |
| 圆角按角色 | 浮窗 `--dsw-radius-panel`(28)、分组与字段 16、紧凑控件 8、胶囊 999 并配 `corner-shape:round` |
| 中性描边 0.5px | 虚线 1px、spinner 环 1.5px 为例外 |
| 浮层无边框 | `border:0` + `--dsw-elevation-panel`；0.5px 发丝线画在阴影第一层，不同时叠中性描边 |
| 滚动条用共享皮肤 | 不写组件私有 `::-webkit-scrollbar` 或 `scrollbar-width/color`；面板内只重绑 `--dsh-scrollbar-*` |
| hover 只在支持的设备启用 | 全部收进 `@media (hover:hover)`；触摸端行操作常显 |
| 动效只动 opacity / transform | 100 / 200ms，`--ds-ease-in-out` |
| 图标画布 36×36 | `icon.svg` 自包含，路径居中缩放 |
| 文案只来自字典 | `src/client/i18n/` 为唯一来源，中英逐键一致；中文提示不带句号 |
| 文案从简 | 主界面只说短句：分区名两字、行内操作用简短动词；解释性长句留在页脚展开内容与错误提示里 |

## 2. 面板基线尺寸

| 项 | 值 |
| --- | --- |
| 入口按钮 | 28×28，R8，待续数为胶囊角标 |
| 面板头 | 标题 14/500 与计数 12/400 同行；关闭按钮位于右侧 |
| 分区标题 | 12/500，`label-secondary` |
| 便笺行 | 无卡片、无分隔线；三列网格 `16px / 正文 / 尾格`，padding 4、R8 悬停底；正文起点与分区标题文字对齐 |
| 左侧填入 | 产品 `IconListPen`，24×24 命中区居中放在正文左侧；归档行保留空位 |
| 尾格 | 时间与操作叠在同一格：静置显示时间，悬停 / 聚焦换成操作，切换不重排正文；触摸端常显操作 |
| 行内图标按钮 | 24×24，R8，间距 2；行尾顺序为「复制 / 退回」。「退回」用产品 `IconRefresh` 水平镜像成逆时针 ↺ |
| 拖动中的行 | `--dsh-an-panelSurface` 底 + `--dsw-elevation-prominent`，其余行用 transform 让位 |
| 录入区 | 0.5px 描边、R16、padding 12；右下角为 28×28、R8 的回车图标按钮，静置时无边框、无底色 |
| 行分隔线 | 0.5px |
| 列表滚动条 | 9px 轨道、2px 内缩、距面板边缘 16px |
| 窄视口 | ≤480px 时四边 12px，宽度按视口夹取 |

对比度（主题令牌的既有值，作为回归参考）：

| 文本 | 明 | 暗 |
| --- | --- | --- |
| 正文 / 标题 `label-primary` | 17.7:1 | 13.6:1 |
| 说明 / 时间 / 计数 `label-secondary` | 5.4:1 | 9.4:1 |
| `label-tertiary`（非文本） | 3.5:1 | 6.7:1 |

`label-tertiary` 不承担文字：明色下只有 3.5:1，文字统一走 `secondary`。

## 3. 交互规则

- **入口**：会话顶部 28×28 按钮，待续数作胶囊徽标；打开时 `data-active`，再次点击、点外部或 Esc 关闭，
  关闭后焦点回到入口。
- **新会话入口**：空白新会话没有 conversation utilities 行，入口落在 header corner（右侧栏按钮左侧），
  只提供工作区清单且不显示「会话」选项；首轮对话后入口回到 utilities，会话清单才可切换。
- **范围提示**：悬停或键盘聚焦「工作区 / 会话」时，说明工作区清单由所有会话共享、会话清单仅当前会话可见；
  空白新会话只有工作区，提示当前只能记到工作区。
- **反馈**：复制、填入、退回、清空归档与写失败都走 `shell.overlay` 的全局 Toast，面板关闭后仍可见；
  失败时不改动任何数据或草稿。
- **归档**：没有手动勾选。「填入」把正文作为纯文本追加到当前会话输入框（已有内容时按换行接上），
  成功后同一步把便笺归档（存储仍是 `done` / `completedAt`）；找不到输入框时什么都不改。
  归档只能「退回」或「清空归档」，按归档时间倒序。
- **排序**：只有待续有手排顺序。直接拖动待续便笺（纵向移动达到 4px 激活，靠近列表上下沿自动滚动）。
  松手写入新顺序，被拖行从松手处滑入新位置。Esc 或指针取消时原样复位，面板保持开启。
  键盘聚焦左侧操作按钮后，↑ / ↓ 每次移动一格并保留焦点。
- **单一编辑区**：只有顶部录入框能编辑便笺正文；行内不再就地编辑。
  点行尾「退回」把正文移回录入框并移除该行，提交后重新加入；录入框已有内容时退回会被拒绝并提示，避免覆盖未提交草稿。
  键位与主会话一致：Enter 发送，Shift+Enter 换行，输入法选词时的 Enter 不提交。
- **六个状态**：默认 / 悬停 / 按下 / 键盘聚焦（主题 2px 环）/ 禁用 / 加载（按钮内 12px 环、`aria-busy`）。
- **浮层安全**：固定定位，由 `body` 下的插件根节点渲染。
  宽高按视口夹取，只在下方确实放不下时才翻到锚点上方。
  顶边不低于 `--dsh-frame-overlay-top`。
  外侧 pointerdown 与 Esc 都能关闭。
- **存储**：页脚的「存储详情」用原生 `details` / `summary` 展开。
  支持文件定位时提供路径、复制和在文件管理器中定位，也可查看当前版本与手动检查更新。
  宿主错误态在面板内直接显示原因与「重新连接」。
- **更新**：仅有新版本时，页脚才显示独立的原生折叠入口「有新版本」。
  展开后可查看说明和发起更新。
- **响应式**：390×844 下四边 12px，标题与操作不截断；触摸设备操作按钮常显。
- **数据**：写失败保持原状；工作区和会话各有清单。
  宿主存储可用时读取已有 `aside_note`，空文件可迁入旧浏览器便笺，具体规则见 [架构](./architecture.md)。

## 4. 测试守护

`npm test` 中的 `tests/contract.test.mjs`（52 条契约测试）与 `tests/bundle.test.mjs`（4
个 jsdom 集成测试）守住本文件的规则。
契约测试守住：

- 颜色 / 字号 / 间距 / 圆角 / 描边 / 浮层材质；
- 滚动条共享皮肤、hover 门控；
- 字典完整、中英一致、中文提示不带句号；
- Toast 座位、写失败保留数据、Tooltip 覆盖行内操作、移动端不主动聚焦；
- 没有勾选框、填入即归档、只有待续可排序、`moveOpenItem` 不动归档的位置、拖动不被入场动画的 `transform` 覆盖；
- 已下线的整页实现不得回流。

jsdom 集成测试真实驱动构建产物：打开面板、添加、Enter / Shift+Enter 键位、方向键与指针拖动排序（含 Esc 取消）、
填入并归档（含找不到输入框）、清除二次确认、退回录入框、键盘缩放、清空到空态、分区记忆。

## 5. 例外与待决

1. **入口按钮使用原生 `title`**：它由插件注入宿主 header 的 DOM（React portal 会被宿主重渲染回收），
   无法包共享 `Tooltip`；若宿主提供 header utilities 插槽，可统一。
2. **右侧浮窗不是侧栏 slot**：当前是锚定入口的浮窗；若产品希望常驻右侧栏，应改注册到 `rightbar`，属产品决策。
3. **链接与错误文本的明色对比度**：`--dsw-alias-link` 3.97:1、`--dsw-alias-state-error-primary` 4.22:1，
   低于 4.5:1；均为主题令牌，建议在主题层统一提升，插件内不覆盖。
4. **图标仍需设计师确认**：`icon.svg` 为 36 画布、自包含 SVG。
