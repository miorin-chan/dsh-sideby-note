# 边记部（Sideby Note）面板 UI 规则

面向后续改动的约束清单。历史复查的过程、逐项对照与截图已移除，只保留规则与待决项；
界面截图及重拍流程见 [截图 SOP](./screenshot-sop.md)。

## 原生输入框能力与组件复用

边记部的录入区以 DSH 原生输入框为基准，尽可能覆盖它的全部功能和交互，并优先使用 DSH 原生组件库。
适配 DSH 新版本时，核对实际输入能力和可复用入口。

| 原生能力 | 边记部的设计目标 |
| --- | --- |
| 编辑 | 对齐选区、撤销与重做、换行、粘贴、输入法、编辑快捷键，以及桌面与触屏的焦点行为 |
| 附件 | 复用文件选择、粘贴、拖放、缩略图、文件卡、预览、上传进度、重试和移除。保存、退回与填入时保留原文件和顺序 |
| 引用 | 接入 `@` 选择器、文件、目录和会话引用，以及对话引文。保存、恢复和填入时保留引用结构 |
| 命令 | 复用 `/` 命令与技能联想、菜单键位和预览。让 DSH 根据会话可用的命令和技能解析草稿 |
| 会话控件 | 对照模型、模式、权限、上下文用量，以及发送、排队、插话、停止和继续生成。按宿主公开入口接入控件与会话操作 |

录入区使用边记部自己的草稿，按工作区或独立会话保存和恢复。
「添加」保存便笺，「填入」将完整内容追加到当前会话草稿。
发送、执行命令和变更会话设置由用户通过明确的会话操作触发，由 DSH 按目标会话的状态和权限处理。

优先通过宿主支持的 Slot、组件工厂或模块入口动态复用原生组件及其行为。
需要适配便笺数据时，只补足数据与操作的衔接。缺少可用入口时，记录对应 DSH 版本的接口缺口，
按[项目约定](../AGENTS.local.md#复用-dsh-原生界面)复用可用的官方代码和样式，或补足最小的插件实现。
当前接入情况见[架构](./architecture.md#原生输入框接入)。

验证新增能力时，用同一 DSH 版本对照原生输入框的键位、焦点、显示和错误反馈，
再按[验收 SOP](./auto-test-sop.md)检查实际交互。
新增可保存的内容类型时，走一遍录入、关闭后恢复、退回编辑和填入，核对保存的内容与顺序。

## 1. 令牌与尺度

以下规则适用于边记部自有界面。复用的 DSH 组件继承宿主主题和无障碍行为，尺寸适配优先使用组件参数和外层布局。

| 规则 | 落地 |
| --- | --- |
| 只用 DSH 语义别名，不自建色板 | `--dsw-alias-*`（墨色 / 悬停 / 描边 / 状态 / 设置卡）；测试禁止 `#hex`、`rgb()` 与平行灰阶 |
| 字号只取三档 | 标题 14/500、行与按钮 13/400、说明与计数 12/400；行高统一 20，计数行 16 |
| 字重上限 500 | 层级靠字号与墨色，不用 600 |
| 圆角按角色 | 浮窗 `--dsw-radius-panel`(28)、分组与字段 16、紧凑控件 8、胶囊 999 并配 `corner-shape:round` |
| 中性描边 0.5px | 虚线 1px、spinner 环 1.5px 为例外 |
| 浮层无边框 | `border:0` + `--dsw-elevation-panel`；0.5px 发丝线画在阴影第一层，不同时叠中性描边 |
| 滚动条用共享皮肤 | 不写组件私有 `::-webkit-scrollbar` 或 `scrollbar-width/color`；面板内只重绑 `--dsh-scrollbar-*` |
| hover 只在支持的设备启用 | 全部收进 `@media (hover:hover)`；触摸端行操作常显 |
| 动效只动 opacity / transform | 100 / 200ms，`--ds-ease-in-out` |
| 图标画布 36×36 | `icon.svg` 自包含，路径居中缩放 |
| 文案只来自字典 | `src/client/i18n/` 为唯一来源，中英逐键一致；中文提示不带句号 |
| 文案从简 | 主界面只说短句：分区名两字、行内操作用简短动词；解释性长句留在页脚展开内容与错误提示里 |

## 2. 面板基线尺寸

| 项 | 值 |
| --- | --- |
| 入口按钮 | 28×28，R8，待续数为胶囊角标 |
| 面板头 | 标题 14/500、范围切换和关闭按钮同行。每个范围显示待续数 12/400。工作区用文件夹图标与名称表示，空间不足时截断名称 |
| 分区标题 | 12/500，`label-secondary` |
| 便笺行 | 无卡片、无分隔线；三列网格 `16px / 正文 / 尾格`，padding 4、R8 悬停底；正文起点与分区标题文字对齐 |
| 全局工作区链接 | 位于正文和附件下方，与内容左对齐。图标和名称共用一个无底色的按钮。当前工作区显示圆点，其他工作区显示箭头。点击图标或名称会在对应工作区打开新会话。未归属或已找不到的工作区仅显示名称 |
| 左侧填入 | 产品 `IconListPen`，24×24 命中区居中放在正文左侧；归档行保留空位 |
| 尾格 | 时间与操作叠在同一格：静置显示时间，悬停或键盘焦点可见时换成操作，切换不重排正文；触摸端常显操作 |
| 行内图标按钮 | 24×24，R8，间距 2；行尾顺序为「复制 / 退回」。「退回」用产品 `IconRefresh` 水平镜像成逆时针 ↺ |
| 拖动中的行 | `--dsh-an-panelSurface` 底 + `--dsw-elevation-prominent`，其余行用 transform 让位 |
| 录入区 | 0.5px 描边、R16、padding 12；正文独占一行并铺满可用宽度，超出高度上限后在输入框内滚动；操作按钮在下一行靠右，其中回车图标按钮为 28×28、R8，静置时无边框、无底色 |
| 行分隔线 | 0.5px |
| 列表滚动条 | 9px 轨道、2px 内缩、距面板边缘 16px |
| 窄视口 | ≤480px 时四边 12px，宽度按视口夹取 |

对比度（主题令牌的既有值，作为回归参考）：

| 文本 | 明 | 暗 |
| --- | --- | --- |
| 正文 / 标题 `label-primary` | 17.7:1 | 13.6:1 |
| 说明 / 时间 / 计数 `label-secondary` | 5.4:1 | 9.4:1 |
| `label-tertiary`（非文本） | 3.5:1 | 6.7:1 |

`label-tertiary` 不承担文字：明色下只有 3.5:1，文字统一走 `secondary`。

## 3. 交互规则

- **入口**：会话顶部 28×28 按钮，待续数作胶囊徽标；打开时 `data-active`，再次点击入口、点面板关闭按钮或按 Esc 可关闭。
  若焦点在面板内，关闭时将焦点还给入口。
- **新会话入口**：空白新会话没有 conversation utilities 行，入口落在 header corner（右侧栏按钮左侧），
  首轮对话后入口回到 utilities。
  「全局」在空白新会话中也可以使用，「工作区」在绑定工作区时可选。
- **列表筛选与计数**：悬停或键盘聚焦范围按钮时，说明筛选口径、完整工作区名称和待续数。
  有工作区时，入口角标固定显示该工作区的待续数。
  独立会话的标题栏和入口都显示全局待续数，标题栏省去切换按钮。
  待读取时用 `—`，入口在计数未就绪或为零时隐藏角标。
  两个范围下的新增便笺都保存到当前工作区，独立会话的新增便笺保存到专用的未分配工作区。
- **切换会话**：点击面板外的会话入口时收起面板，会话照常切换。
  通过键盘切换或使用面板内的跳转链接时，保留面板状态。
  打开的面板随当前会话更新，不主动抢焦点。
  从全局便笺跳到工作区或从条目打开绑定会话时，仍定位原条目。
- **会话绑定**：空白新会话不能新建绑定，仍可添加未绑定便笺，也可解除草稿或已有条目的绑定。
  会话开始后，录入区默认绑定当前会话，点击绑定图标可解绑。
  录入区用高亮的完整链条表示已绑定，斜杠链条表示未绑定。
  条目按钮不用高亮，完整链条表示绑定动作，斜杠链条表示解绑动作。
  提示文案说明点击后的动作。工作区与会话跳转在条目下方同行显示，同时出现时用 `/` 分隔。
  筛选和计数不变。打开绑定会话不写草稿，在其他会话时「填入」不可用。
- **反馈**：复制、填入、退回、清空归档与写失败都走 `shell.overlay` 的全局 Toast，面板关闭后仍可见；
  混合填入中断且草稿已有部分内容时，提示先处理该处改动再重试。
- **归档**：「填入」把正文和全部附件带进当前会话草稿，确认接收后在便笺所属工作区归档（存储为 `done` / `completedAt`）。
  读取附件期间按钮显示加载状态，会话附件栏提供后续上传状态。
  输入框不可用或拒收附件时，便笺保持待续。草稿已接收而归档失败时，提供「重试归档」。
  归档可「退回」或「清空归档」。
- **排序**：默认待续按创建时间倒序，归档按归档时间倒序，不区分工作区。
  分区展开时，悬停或键盘聚焦标题会显示排序控件，触屏上常显。
  分区收起时不提供排序控件。各分区在浏览器内分别记住选择。
  「按工作区」将当前工作区放在最前，组内由绑定当前会话的便笺优先，各组内其余条目按时间倒序。
  「手动排序」仅用于待续，拖动和键盘移动都限于便笺所属工作区。
  手动排序时纵向移动达到 4px 激活拖动，靠近列表上下沿自动滚动。
  松手写入新顺序，被拖行从松手处滑入新位置。
  Esc、指针取消或列表在拖动中重排时，结束拖动，面板保持开启。
  键盘聚焦左侧操作按钮后，↑ / ↓ 每次移动一格并保留焦点。
- **单一编辑区**：只有顶部录入框能编辑便笺正文；行内不再就地编辑。
  点行尾「退回」把正文与附件移回录入框并移除该行，提交后加入原工作区。
  录入框已有内容时提示先处理当前草稿。
  当前录入框按 Enter 添加便笺，按 Shift+Enter 换行，输入法选词时的 Enter 交给输入法。
- **六个状态**：默认 / 悬停 / 按下 / 键盘聚焦（主题 2px 环）/ 禁用 / 加载（按钮内 12px 环、`aria-busy`）。
- **浮层安全**：固定定位，由 `shell.overlay` 通过 portal 渲染到 `body`。
  宽高按视口夹取，只在下方确实放不下时才翻到锚点上方。
  顶边不低于 `--dsh-frame-overlay-top`。点击面板外部可收起，保留目标的操作和焦点。
  面板内打开的预览仍算面板的一部分。
- **存储与更新**：页脚的「存储与更新」用原生 `details` / `summary`，默认折叠。
  展开后显示存储状态、当前版本和手动检查更新按钮。
  支持文件定位时提供路径、复制和在文件管理器中定位。
  宿主错误态在面板内直接显示原因与「重新连接」。
- **更新**：仅有新版本时，页脚才显示独立的原生折叠入口「有新版本」。
  展开后可查看说明和发起更新。
- **响应式**：390×844 下四边 12px，标题与操作不截断；触摸设备操作按钮常显。
- **数据**：写失败保持原状。便笺按工作区保存，旧会话记录会迁入工作区，具体规则见 [架构](./architecture.md#4-数据模型)。

## 4. 测试守护

`npm test` 中的 `tests/contract.test.mts`（52 条契约测试）与 `tests/bundle.test.mts`（4
个 jsdom 集成测试）守住本文件的规则。
契约测试守住：

- 颜色 / 字号 / 间距 / 圆角 / 描边 / 浮层材质；
- 滚动条共享皮肤、hover 门控；
- 字典完整、中英一致、中文提示不带句号；
- Toast 座位、写失败保留数据、Tooltip 覆盖行内操作、移动端不主动聚焦；
- 没有勾选框、填入即归档、只有待续可手动排序、`moveOpenItem` 不动归档的位置、拖动不被入场动画的 `transform` 覆盖；
- 已下线的整页实现不得回流。

jsdom 集成测试真实驱动构建产物：打开面板、添加、Enter / Shift+Enter 键位、方向键与指针拖动排序（含 Esc 取消）、
填入并归档（含找不到输入框）、清除二次确认、退回录入框、键盘缩放、清空到空态、分区记忆。

## 5. 例外与待决

1. **入口按钮使用原生 `title`**：它由插件注入宿主 header 的 DOM（React portal 会被宿主重渲染回收），
   无法包共享 `Tooltip`；若宿主提供 header utilities 插槽，可统一。
2. **右侧浮窗不是侧栏 slot**：当前是锚定入口的浮窗；若产品希望常驻右侧栏，应改注册到 `rightbar`，属产品决策。
3. **链接与错误文本的明色对比度**：`--dsw-alias-link` 3.97:1、`--dsw-alias-state-error-primary` 4.22:1，
   低于 4.5:1；均为主题令牌，建议在主题层统一提升，插件内不覆盖。
4. **图标仍需设计师确认**：`icon.svg` 为 36 画布、自包含 SVG。
